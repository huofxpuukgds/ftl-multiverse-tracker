## Overview

FTL: Multiverse Run Tracker helps players track progress in FTL: Faster Than Light's massive Multiverse mod, recording which ships have been unlocked, which endings have been achieved, which crew species have been recruited, and which hidden events have been triggered — compiling the completion status of Multiverse's expansive content into one dashboard.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FTL Multiverse Run Tracker** delivers the features you need in a clean, intuitive package.
